# FitLife - Your Personal Gym Buddy

FitLife adalah aplikasi mobile komprehensif yang dirancang untuk menjadi asisten kebugaran pribadi Anda. Aplikasi ini membantu pengguna dalam memandu latihan, memantau progres, dan memberikan motivasi sosial untuk mencapai gaya hidup sehat. Dengan antarmuka yang intuitif dan fitur pelacakan yang kuat, FitLife adalah teman terbaik Anda di setiap langkah perjalanan kebugaran.

## ✨ Fitur Utama

* **Autentikasi Pengguna & Profil:**
    * Registrasi dan Login akun menggunakan Email & Kata Sandi.
    * Manajemen Kata Sandi (ubah kata sandi).
    * Profil yang dapat disesuaikan: Unggah/ganti Foto Profil, Edit Bio, dan Tanggal Lahir.
    * Input data biometrik (Tinggi, Berat, Usia, Gender) untuk kalkulasi BMI otomatis.
* **Pelacakan Latihan & Aktivitas:**
    * **Katalog Gerakan Latihan:** Berbagai jenis latihan dikategorikan menjadi "Cardio" (Running, Jump Rope, Burpees, dll.) dan "Weight Training" (Bench Press, Squat, Deadlift, dll.) lengkap dengan deskripsi, manfaat, dan estimasi kalori per set.
    * **"Free Run" Manual:** Catat aktivitas lari dengan menginput jarak dan waktu tempuh, aplikasi akan mengkalkulasi kalori terbakar.
    * **"My Plan":** Tambahkan gerakan latihan ke rencana pribadi Anda.
* **Manajemen Kalori Harian:**
    * Input kalori yang dikonsumsi per hari.
    * Lacak kalori yang terbakar dari seluruh aktivitas.
* **"Recap" Harian:**
    * Dapatkan ringkasan visual komprehensif dari semua aktivitas dan total kalori terbakar dalam satu hari.
    * Opsi untuk menyimpan Recap sebagai foto atau membagikannya ke media sosial.
* **Jaringan Sosial (Teman & Chat):**
    * Kelola daftar teman: Tambah teman menggunakan kode unik, terima/tolak permintaan pertemanan.
    * Fitur Chat langsung dengan teman.
* **Pengaturan Aplikasi:**
    * Akses ke pengaturan profil dan akun.

## 🚀 Teknologi yang Digunakan

* **Framework:** Flutter
* **Bahasa Pemrograman:** Dart
* **IDE:** Android Studio
* **Version Control:** Git & GitHub
* **State Management:** Provider / Riverpod
* **HTTP Client:** Dio
* **Routing:** go_router
* **Local Storage:** shared_preferences
* **API:** REST API
* **Database:** PostgreSQL (untuk data terstruktur utama) & Firebase (untuk penyimpanan media seperti foto profil, postingan).

## 🎨 Desain & UI/UX

FitLife menampilkan antarmuka pengguna yang intuitif dan energik dengan skema warna **gradasi merah ke hitam**, menciptakan pengalaman visual yang modern dan memotivasi. Navigasi dirancang agar mudah diikuti dan konsisten di seluruh aplikasi.
